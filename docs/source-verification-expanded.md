## 남은 주의점

- `quote` 필드는 현재 한국어 요약문으로 쓰며, UI에서는 직접 인용이 아니라 `출처 기반 요지` 또는 `초안 요지`로 표시한다.
- 현대 저자, 임상/의학, 최신 정책 자료는 공개 전환 전에 날짜와 기관 신뢰도를 더 엄격히 확인한다.
- 건강/몸 카테고리는 최소 2개 이상의 공식/의료기관 출처와 안전 문구가 붙기 전까지 sitemap에 넣지 않는다.
- 정책 논쟁은 통계 기준 시점과 법령 시행 상태가 바뀔 수 있으므로 정기적으로 최신 자료를 재확인한다.
