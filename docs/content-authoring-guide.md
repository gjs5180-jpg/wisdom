# 콘텐츠 작성 가이드

위즈덤의 콘텐츠 단위는 검색어가 아니라 canonical node입니다. 여러 표현을 하나의 카드에 묶고, 그 안에서 감정, 상황, 관점, 실천을 정리합니다.

## 좋은 카드의 구조

카드 하나는 아래 질문에 답해야 합니다.

1. 사용자가 실제로 어떤 말로 이 고민을 검색할까?
2. 이 고민의 감정은 무엇인가?
3. 이 고민의 상황은 무엇인가?
4. 사용자가 진짜로 묻는 핵심 질문은 무엇인가?
5. 서로 다른 관점은 어디서 갈라지는가?
6. 검증된 출처와 확인 중인 출처는 어떻게 구분되는가?
7. 읽은 뒤 바로 해볼 수 있는 작은 행동은 무엇인가?
8. 다음에 이어서 볼 카드는 무엇인가?

## 카드 초안 템플릿

```text
제목:
사용자 문장:
핵심 감정:
핵심 질문:

관점 1:
- 인물/출처:
- 요지:
- 출처 상태: verified | checking

관점 2:
- 인물/출처:
- 요지:
- 출처 상태: verified | checking

주의할 점:
오늘 해볼 작은 행동:
관련 카드:
관련 태그:
언어권 신호:
```

## 출처 기준

- 원전, 공식 문서, 논문, 신뢰 가능한 기관 자료를 우선합니다.
- 정확한 문구가 확인되지 않으면 인용문처럼 쓰지 않습니다.
- 살아있는 사람의 발언은 특히 조심합니다.
- 출처가 약한 관점은 "요지"로 표시하고, 확인 중 상태를 남깁니다.
- 좋은 말처럼 보여도 출처가 애매하면 카드의 중심 근거로 쓰지 않습니다.

## 언어권 수집 기준

언어권 수집은 번역 작업이 아닙니다.

- 일본어 고민을 일본어 페이지로만 만드는 것이 아닙니다.
- 일본어, 영어, 중국어, 스페인어 등에서 수집한 표현을 같은 canonical node에 합칩니다.
- 그 다음 한국어, 영어 등 출력 언어별 페이지를 씁니다.
- 수집 표현은 실제 사람 수가 아니라 관심 신호입니다.

## 태그 기준

태그는 같은 카드를 여러 입구에서 다시 찾게 해주는 장치입니다.

- 감정 태그: 불안, 슬픔, 수치심, 외로움, 공허, 분노
- 상황 태그: 이별, 가족, 직장, 공부, 돈, 건강
- 판단 태그: 선택, 후회, 통제 불가, 가치 충돌

태그가 너무 많으면 의미가 흐려집니다. 한 카드에는 핵심 태그를 우선합니다.

## 품질 체크리스트

- 제목만 봐도 사용자가 자기 문제라고 느끼는가?
- 첫 문단이 추상적 설명이 아니라 실제 고민에서 출발하는가?
- 관점들이 서로 다른 기준을 보여주는가?
- 출처 확인 중인 내용을 확정처럼 말하지 않는가?
- 마지막에 관련 카드로 자연스럽게 이어지는가?
- 영어 버전 또는 영어 seed 업데이트가 필요한가?
