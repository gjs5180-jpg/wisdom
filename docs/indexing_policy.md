## 색인 포함

- 홈, 대분류/중분류 탐색 페이지
- verified 카드가 2개 이상인 고민/논쟁/생각 상세 페이지
- 공개 콘텐츠가 2개 이상 연결된 태그 페이지
- 카드가 2개 이상 연결된 인물 페이지

## 색인 제외

- /collected: 수집/검토 운영 지도이므로 noindex
- /saved: 개인 저장함 UI이므로 robots disallow
- 검증 중 초안 상세: 접근은 허용하지만 page metadata robots.index=false
- 저신호 표현: canonical content의 중심 문장으로 쓰지 않음

## 공개 전환 조건

1. 최소 2개 카드의 출처와 관점이 확인된다.
2. 직접 인용처럼 보이는 문구는 원문과 번역 맥락을 대조한다.
3. 행동 지침이 출처의 주장보다 과장되지 않는다.
4. 수집어 기반 대표 질문과 사용자 입구 문장이 실제 검색 의도와 맞는다.
