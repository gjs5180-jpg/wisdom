# Wisdom 콘텐츠 방향

Wisdom은 명언 모음이 아니라, 사람들이 실제로 검색하는 고민·생각·논쟁을 신뢰 가능한 관점으로 정리하는 사이트다.

## 범위

다룰 수 있는 범위는 넓게 잡는다.

- 생활 고민: 다이어트, 외모 콤플렉스, 자격증 시험, 공부, 퇴사, 돈 걱정
- 관계 고민: 연애, 이별, 친구, 가족, 부모님, 인간관계 정리
- 마음의 질문: 자존감, 공허함, 죽음, 무기력, 삶의 의미
- 사회 논쟁: 사형제, 촉법소년, 동물실험, 안락사, 노키즈존
- 미래 논쟁: AI 일자리, AI 예술, 기본소득, 능력주의

검색어 하나가 곧 페이지가 되지는 않는다. 비슷한 검색어를 하나의 canonical node로 묶고, 그 노드에 저명한 사람의 관점이나 신뢰도 높은 해답을 붙인다.

## 방향성

철학자의 관점만 다루는 사이트로 좁히지는 않는다. 철학과 사상은 Wisdom의 중심 언어지만, 사용자가 실제로 해결하고 싶은 고민은 건강, 관계, 제도, 습관, 법, 돈, 기술까지 넓게 이어진다. 따라서 카드는 다음 네 관점 축으로 정리한다.

- 철학 / 사상: 고전 원전, 사상가, 윤리적 기준, 삶의 큰 질문을 다룬다.
- 연구 / 임상: 심리, 건강, 학습, 행동 변화처럼 근거 기반 설명이 필요한 주제를 다룬다.
- 제도 / 정책: 논쟁 주제에서 법, 공공기관 자료, 제도적 비용과 권리 충돌을 분리한다.
- 실천 / 적용: 독자가 오늘 해볼 수 있는 질문, 행동, 판단 절차로 연결한다.

브랜드의 중심 문장은 "실제 고민을 철학, 연구, 제도, 실천의 관점으로 정리하는 지식 지도"로 둔다. 철학은 차별성의 중심이고, 연구와 제도는 신뢰성을 보강하며, 실천은 페이지를 읽고 끝나지 않게 만든다.

## 해외 확장

다국어 확장은 단순 번역이 아니라 언어권별 고민 표현을 다시 수집하는 방식으로 진행한다.

- 한국어, 영어, 일본어 등 언어권마다 검색어와 커뮤니티 표현이 다르므로 canonical phrase를 별도로 모은다.
- URL은 장기적으로 `/ko`, `/en`, `/ja` 같은 locale prefix와 `hreflang`을 고려한다.
- 같은 노드라도 언어권별 대표 입구 문장은 다를 수 있다. 예: `좋은 삶`, `good life`, `ikigai`는 완전히 같은 말처럼 취급하지 않고 맥락을 비교한다.
- 해외권 콘텐츠도 원전, 공식 기관, 연구 자료를 우선하고, 유명인의 말은 출처와 맥락이 확인될 때만 카드화한다.
- 문화권에 따라 민감도가 다른 논쟁은 결론을 번역하지 않고 쟁점 구조를 현지 맥락에 맞게 다시 쓴다.

## 대·중·소 구조

1. 대분류: `고민`, `생각`, `논쟁`
2. 중분류: 관계, 자아/마음, 현실/미래, 삶/행복, 성공/인정, 법/생명 윤리, 가족/문화, 기술/경제 등
3. 소분류: 실제 페이지 단위. 예: `공부가 안 될 때`, `좋은 삶이란 무엇인가?`, `사형제, 유지해야 하나?`

URL은 당장 크게 바꾸지 않는다. 먼저 데이터와 화면에서 구조를 안정화하고, 필요할 때 라우팅을 재설계한다.

## 감정·상황 태그

대·중·소 분류는 콘텐츠의 기본 주소이고, 태그는 콘텐츠를 가로지르는 보조 렌즈다.

- 감정 태그: 불안, 슬픔, 수치심, 외로움, 공허, 압박감 등
- 상황 태그: 통제 불가, 선택, 습관, 연애, 이별, 공부/시험, 돈/미래, 윤리 등
- 같은 인물 카드라도 카드가 쓰인 맥락에 따라 여러 태그 섹션에 동시에 걸릴 수 있다.
- 태그 페이지는 최소 2개 이상의 공개 노드가 있을 때 검색 노출 대상으로 본다.

## 인물별 탐색

인물 페이지는 새 글을 따로 쓰는 곳이 아니라, 기존 검증 카드가 모이는 색인이다.

- 같은 사상가가 여러 고민·생각·논쟁에서 반복 등장하는 패턴을 보여준다.
- 인물 페이지는 카드 2개 이상부터 검색 노출 대상으로 본다.
- 기관·법제처럼 인물이 아닌 카드는 별도 기준/기관 축이 생기기 전까지 인물 목록에서 제외한다.
- 상위 인물은 대표 관점 요약과 소개문을 둔다. 새 글을 쓰기보다 이미 검증된 카드의 반복 패턴을 설명한다.

## 논쟁 섹션

논쟁은 카테고리뿐 아니라 입장 렌즈로도 탐색한다.

- 찬성 / 허용: 질문에 긍정하거나 제도·행위 유지를 옹호하는 입장
- 반대 / 금지: 폐지, 금지, 강한 제한을 말하는 입장
- 조건부 / 절충: 상황, 결과, 기준, 대체 제도에 따라 판단하는 입장
- 사실 / 제도 정리: 찬반 이전에 개념과 현행 기준을 정리하는 입장

## 출처 신뢰도

카드는 세 층으로 나눈다.

| 등급 | 예시 | 공개 기준 |
| --- | --- | --- |
| 원전 / 공식 기준 | 고전 원문, 법령, 공식 기관 문서 | 직접 문구 또는 요지를 확인하면 `verified: true` |
| 전문가 / 연구 | 논문, 전문기관, 검증된 저작 | 출처와 맥락을 확인하면 `verified: true` |
| 해설 / 요지 | 현대적 적용, 해석, 2차 해설 | 직접 문구가 불확실하면 `verified: false` |

하나의 페이지는 최소 2개 이상의 검증 카드가 있어야 검색 노출 대상이 된다.

## 좋은 페이지의 형태

- 사용자가 검색하는 언어로 제목을 쓴다.
- 상단에 감정 또는 논쟁의 핵심을 한 줄로 정의한다.
- 여러 입장을 나란히 둔다. 하나의 정답처럼 말하지 않는다.
- 저명한 사람의 관점은 원전·출처·맥락을 함께 둔다.
- 고위험 주제는 행동 지침을 조심스럽게 쓰고, 전문 도움이나 공식 기준을 우선한다.
- 마지막에는 독자가 바로 해볼 수 있는 작은 질문이나 행동을 남긴다.

## 운영 원칙

- 얇은 페이지를 많이 만들지 않는다.
- 플랫폼 글 본문은 복사하지 않는다.
- 검색어와 고민 표현만 수집하고, 본문은 새로 작성한다.
- 사적인 사례는 일반화해 재작성한다.
- 논쟁 글은 찬반 구도를 세우되, 피해자·당사자·제도 맥락을 단순화하지 않는다.
