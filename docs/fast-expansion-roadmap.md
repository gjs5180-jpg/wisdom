# 빠른 확장 로드맵

위즈덤을 빠르게 키울 때는 수집량, 콘텐츠 품질, 사용 흐름을 같이 봐야 합니다. 지금 우선순위는 아래 순서입니다.

## 1. 협업 속도 만들기

목표: 친구가 저장소를 받고 바로 작업할 수 있게 한다.

- README 정리
- 협업 가이드 정리
- 카드 작성 템플릿 정리
- PR 체크리스트 추가
- 새 카드 담당 영역 나누기

## 2. 상세 페이지 체류시간 늘리기

목표: 카드 하나를 읽고 바로 나가지 않게 한다.

- 관련 고민 카드 노출
- 연결된 논쟁과 큰 질문 노출
- 같은 감정/상황 태그 노출
- 관련 인물 노출
- 언어권 관심 신호를 다음 탐색 이유로 보여주기

## 3. 홈 검색을 탐색 도구로 만들기

목표: 검색 결과가 단순 카드 목록이 아니라 사이트 전체 입구가 되게 한다.

- 카드, 카테고리, 태그, 인물을 함께 검색
- 검색 결과를 유형별로 묶기
- 검색어가 없을 때는 추천 흐름 노출
- 결과가 없을 때는 가까운 입구 제안

## 4. 콘텐츠 품질 템플릿 통일

목표: 카드가 많아져도 품질이 흔들리지 않게 한다.

- 사용자 문장
- 핵심 감정
- 핵심 질문
- 관점별 정리
- 출처 상태
- 조심할 점
- 오늘의 작은 행동
- 관련 카드
- 언어권 신호

## 5. 첫인상 다듬기

목표: 처음 들어온 사람이 5초 안에 이해하게 한다.

- 위즈덤이 무엇을 하는 사이트인지 홈 첫 문장에 명확히 쓰기
- "답을 주는 사이트"가 아니라 "관점 지도를 만드는 사이트"로 포지셔닝
- 친구 피드백은 디자인보다 이해도와 검색 욕구를 먼저 본다.

## 이번 주 추천 작업

1. 상세 페이지 하단 관련 탐색 강화
2. 홈 검색 결과 유형별 그룹화
3. 친구 2명에게 공유 후 첫인상 피드백 받기
4. 피드백을 `docs/feedback-log.md`에 기록
5. 많이 헷갈린 지점부터 수정
