# 피드백 로그

친구에게 공유한 뒤 받은 반응을 이 파일에 남깁니다. 좋은 말보다 헷갈린 지점이 더 중요합니다.

## 기록 템플릿

```text
날짜:
피드백 준 사람:
어떤 기기로 봤는지:
처음 이해한 내용:
헷갈린 부분:
검색해본 단어:
눌러본 카드:
읽다가 멈춘 지점:
좋았던 부분:
바꾸면 좋겠다는 말:
다음 액션:
```

## 질문 예시

- 이 사이트가 뭘 하는 곳인지 5초 안에 이해됐어?
- 가장 먼저 검색해보고 싶은 단어가 뭐였어?
- 카드 상세 페이지에서 계속 읽고 싶었어, 아니면 나가고 싶었어?
- 너무 철학적으로 느껴졌어, 아니면 실용적으로 느껴졌어?
- 친구에게 설명한다면 뭐라고 말할 것 같아?
