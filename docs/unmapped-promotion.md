# 미분류 후보 승격 메모

생성일: 2026-06-19

원칙: 검색어 하나를 페이지 하나로 만들지 않는다. 반복되는 검색 의도는 기존 canonical node에 흡수하고, 기존 노드로 설명되지 않는 묶음만 새 노드로 승격한다.

## 이번 반영

아래 검색어 묶음은 새 페이지보다 기존 노드에 붙이는 편이 자연스럽다.

| 후보 묶음 | 처리 | 이유 |
| --- | --- | --- |
| `sns 비교`, `인스타 현타`, `sns 비교 우울` | `self-esteem/comparing` intent에 흡수 | 핵심 감정이 디지털 사용 자체보다 비교와 열등감이다. |
| `관계 정리`, `인간관계 손절`, `인간관계 리셋` | `relationships/drifting-friends` intent에 흡수 | 친구 관계가 멀어지는 문제와 같은 canonical node에서 다룰 수 있다. |
| `부모님 기대`, `부모님 종교 갈등`, `형제 비교` | `family/parent-conflict` intent에 흡수 | 가족 갈등과 독립 노드의 하위 입구로 처리하는 편이 얇은 페이지를 줄인다. |
| `수험생 슬럼프`, `자격증 공부 방법`, `집중 안되는 이유` | `study/cant-study` intent에 흡수 | 공부가 안 되는 상황의 구체 입구로 충분히 포괄된다. |

## 이번 노출 슬롯 추가

아래 묶음은 검색 의도가 선명하고 기존 카테고리로는 흡수하기 어려워 준비 중 노드로 승격했다. 검증 카드가 붙기 전까지는 `noindex` 상태를 유지한다.

| 신규 노드 | URL | 이유 |
| --- | --- | --- |
| `body/body-anxiety` | `/body/body-anxiety` | 외모 콤플렉스, 다이어트 강박, 피부 스트레스가 하나의 몸 불안 축으로 묶인다. |
| `career/dream-reality` | `/career/dream-reality` | 꿈 포기, 돈 때문에 꿈 포기, 현실과 꿈의 충돌 검색어가 반복된다. |
| `love/attachment-anxiety` | `/love/attachment-anxiety` | 불안형 연애와 회피형 연애 검색 수요가 크고 기존 짝사랑 노드와 구분된다. |
| `breakup/ghosting` | `/breakup/ghosting` | 잠수이별과 읽씹은 일반 이별 회복보다 '무시당함'과 통제 불가능성이 핵심이다. |

## 다음 카드 초안 후보

1. `body/body-anxiety` — 외모 콤플렉스와 몸이 싫을 때
   - 후보 검색어: 외모 콤플렉스 극복, 다이어트 강박, 몸이 안 좋을 때
   - 상태: 노출 슬롯 추가 완료, 카드 초안 필요
   - 카드 후보: 스피노자, 에픽테토스, 불교 또는 메를로퐁티

2. `career/dream-reality` — 꿈을 포기해야 할지 고민될 때
   - 후보 검색어: 꿈 포기, 돈 때문에 꿈 포기, 아이돌 꿈 포기
   - 상태: 노출 슬롯 추가 완료, 카드 초안 필요
   - 카드 후보: 카뮈, 키르케고르, 아리스토텔레스

3. `love/attachment-anxiety` — 불안형 연애를 할 때
   - 후보 검색어: 불안형 연애, 회피형 연애, 애착 불안
   - 상태: 노출 슬롯 추가 완료, 카드 초안 필요

## 보류 / 노이즈

- 플랫폼명만 붙은 검색어는 독립 페이지로 만들지 않는다. 예: `디시`, `더쿠`, `블라인드`.
- 유명인·정당·게임명 등 특정 사건성이 강한 검색어는 일반 고민으로 바로 승격하지 않는다.
- 법률·의학·정신건강 고위험 주제는 검증 출처 2개 이상 확보 전까지 `noindex` 원칙을 유지한다.
