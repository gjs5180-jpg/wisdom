## 처리 원칙

1. 의미가 분명한 표현은 상세 페이지의 질문 구조, 대표 질문, 검색 의도별 답변에 반영한다.
2. 커뮤니티 사례 표현은 실제 사례 욕구로 보되, 출처 검증 카드와 분리해 읽게 한다.
3. 가사, 작품명, 상품명, 행정서류, 꿈/해몽 표현은 별도 얇은 페이지로 만들지 않고 검토 노트와 전체 수집 표현에만 남긴다.
4. 같은 의도의 표현이 충분히 반복되면 새 canonical node 후보로 승격한다.
